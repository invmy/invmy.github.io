# Hi! 👋 I’m Guava.

## ✨ Function
- Deployed on `GitHub Pages`.
- Build using `GitHub Actions`.
- CMS using `GitHub Discussion`.
- Comments using `Giscus`

## 🚀 Getting Started

You only need to have a GitHub account.

Deploy a blog in minutes

Simply put: clone the project, enable the feature, and start the build.
